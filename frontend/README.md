# Frontend - File Upload & AI Analysis UI

Modern, responsive web interface for file upload and AI analysis.

## Quick Start

**Option 1: Direct File Open**
- Open `index.html` in your web browser

**Option 2: Local Server (Recommended)**
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`

**Option 3: VS Code Live Server**
- Install "Live Server" extension
- Right-click `index.html` → "Open with Live Server"

## Features

- Drag and drop file upload
- Real-time upload progress
- Display AI analysis results
- Browse previously uploaded files
- Responsive design (mobile-friendly)
- Modal view for file details

## Configuration

Edit `script.js` to change:
- `API_URL`: Backend API endpoint (default: `http://localhost:5000`)

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `script.js` - JavaScript logic and API calls

## Browser Support

- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers
