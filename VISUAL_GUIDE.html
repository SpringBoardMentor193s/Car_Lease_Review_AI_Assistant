🚀 Car Lease AI Assistant - Visual Startup Guide

⚡ Quick Answer: Just double-click golive.bat and you're done!

1Open File Explorer

Press Windows Key + E or click the folder icon in your taskbar

2Navigate to Project Folder

Go to: d:\infosys\Car_Lease_Review_AI_Assistant

3Find golive.bat

Look for this file: 📄 golive.bat

4Double-Click It

A black window (terminal) will open and show progress

5Wait for Completion

You'll see messages like:

  • ✅ Docker is running
  • ✅ PostgreSQL is ready
  • ✅ Dependencies installed
  • ✅ Database initialized

6Application Started!

When you see:

🚀 Starting Application...
📍 Application URLs:
   • API Server: http://localhost:8000

Your application is running! 🎉

7Access the Application

Open your web browser and go to:

  • API Docs: http://localhost:8000/docs
  • Database UI: http://localhost:5050
🛑 To Stop: Press Ctrl+C in the terminal window

⏱️ Timing

  • First Run: 2-5 minutes (downloads everything)
  • Subsequent Runs: 10-15 seconds

🔧 Requirements

  • Docker Desktop (must be running)
  • Python 3.8 or higher
  • ~500MB free disk space

❓ Troubleshooting

"Docker is not running"

  1. Open Docker Desktop from Start Menu
  2. Wait for the whale icon to appear in system tray
  3. Run golive.bat again

"Python not found"

  1. Download Python from python.org
  2. During installation, check "Add Python to PATH"
  3. Restart your computer
  4. Run golive.bat again
